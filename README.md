One small program, one small text. It writes a few sentences about the end of a day — a dog asleep against your leg with all its weight given over, a street gone quiet, tea still warm in your hands — to `/output/entry.txt`, for the AI judge of this make.fun bounty to read. Nothing in the text tells the reader to relax; the leaning dog is meant to do that part.

## Run it

```sh
node main.ts
```

It writes `entry.txt` into `/output` (or into `$OUTPUT_DIR` when that is set).
